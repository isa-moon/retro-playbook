# 经验沉淀：抖音达人种草项目（来源：澄言修护精华项目，2026-09）

> 用法：新项目 kickoff 前对照检查一遍，每条后面写着出处案例。

## A. Brief 阶段

- [ ] **卖点合规预检**：逐条列出核心卖点，标注是否属于功效宣称（修复、修护、美白、抗皱、祛痘等），并确认有没有功效评价报告。没有报告的，当场跟客户定替代说法，或者等报告出来再排期。
  - 案例：澄言「28 天修复屏障」没有报告，上线前 5 天被法务驳回，3 条重拍、延期 7 天，受影响腰部的 CPM 从 19 涨到 44。
- [ ] **确认客户内部审核链路**：市场部和法务谁说了算？法务审核的 SLA 是几天？kickoff 会上让客户法务也到场，或者至少拿到书面确认。
- [ ] **KPI 口径写清楚**：CPM 含不含投流、算加权（总费用/总播放）还是简单平均；搜索增幅的基准期和数据来源。
- [ ] **每个 KPI 都要对应执行动作**：有搜索 KPI，就要设计搜索引导（口播"天猫搜 XX"、搜索组件、评论区置顶）。

## B. 达人签约和排期

- [ ] 口头确认档期后 **48 小时内签合同或付定金**，合同写明档期违约和改档条款。
  - 案例：阿May 口头确认后没签，被别的品牌年框挤掉，延期一周，CPM 58。
- [ ] 头部按 **1:1 备选**；头部不排在上线首日，最好排在第 2~4 天，留出补位时间。
- [ ] 排期表留 **3~5 天缓冲**，最晚一批不要排到窗口最后一周（种草对搜索有滞后）。

## C. 脚本和审核

- [ ] 审核分三步：**卖点话术预审 → 脚本审 → 成片审**。卖点话术要在达人开写之前过法务。
- [ ] 脚本交给法务 2 个工作日没回复就主动催，同步给客户对接人。
- [ ] 维护一份"功效宣称禁用词 / 替代词"对照表，每个项目都补充更新。

## D. 选号和数据质量

- [ ] 选号阶段做刷量筛查：评论/播放、评论/点赞明显高于同类账号（比如超过 3 倍）的，抽查评论内容，模板化好评占比高的直接排除。
  - 案例："干皮的自救"评论/播放 0.73%，同类账号约 0.05%；评论/点赞 30%，同类约 6.5%；评论基本是"好用""已买"。
- [ ] 投放中发现数据异常，**当周告知客户**，向机构追责，账号进黑名单。不要拖到结案。

## E. 投放和加热

- [ ] 预算结构：**腰部铺量赛马，再给跑出来的追加投流**。投流预算留 30%~50% 机动，用来追加。
  - 案例：成分党小周、护肤小白兔、屏障修复手册 CPM 16~18，腰部整体 CPM 25.7，头部 45.2。
- [ ] 加热规则写进方案：上线 48 小时内，CPM 低于目标 50% 且互动率正常的，追加投流。
- [ ] 投流花费逐条记录（投给哪条、多少钱、新增多少播放），结案时自然流和付费流分开算。

## F. 结案和复盘

- [ ] 结案数据按 kickoff 约定的口径算，剔除异常数据后再看一遍 KPI 是否达成。
- [ ] 复盘结论要写成"现象 → 根因 → 具体动作 → 负责人 → 时限"，不要写"下次注意""加强沟通"这类没法检查的话。
- [ ] 归因要拆变量：比如腰部表现好，要区分"量级好"、"按时上线、没返工"和"吃到了投流加热"。
