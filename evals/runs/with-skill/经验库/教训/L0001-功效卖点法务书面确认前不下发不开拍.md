## 发生了什么（事实）
- brief（08-20）核心卖点为「28 天修复屏障」「敏感肌可用」；08-25 客户市场部要求「脚本统一用『28天修复屏障』做主卖点」，08-26 我方同步给 10 位腰部达人。
- 脚本 08-28 交客户法务；09-10 法务回复：「所有脚本里『修复』『修护屏障』属于功效宣称，需要有功效评价报告支撑，我们报告还没出，先全部改成『舒缓』『维稳』」。
- 09-11：「已经拍完的 3 条要重拍，敏敏 / Kiki / 阿杰档期都要往后」。结案数据：三条计划 09-17/18/20，实际 09-24/25/27，备注「法务驳回脚本两次」「脚本返工」「法务驳回；改卖点」。
- 三条 CPM 33.7 / 48.3 / 57.4；按时上线、未返工的腰部（小周、小白兔、屏障修复手册、学生党护肤）CPM 16.3 / 15.7 / 18.2 / 27.6。（来源：结案数据.csv、群聊摘录.md）

## 为什么（推断）
- 用户确认的归因：表现差的几条是因为被改卖点、重拍延期；表现好的几条按时上线、没被改卖点。
- 机制缺口：卖点由市场部定稿后直接下发达人，拍摄没有等法务结论；功效报告是否存在在 kickoff 时没人核验。
- 未排除的混杂：小周、小白兔 09-19 加热过 3 万投流，播放里自然流与付费流未拆分（把 3 万计入后按时组 CPM 为 24.2，仍明显低于返工组）；返工组上线更晚，窗口内累积时间更短。法务原话是「全部改成」，按时组是否仍用原卖点材料未记载。
