# 复盘书 · Retro Playbook

> 让同一个坑只踩一次。

大多数团队都复盘，但复盘完的经验很少在下个项目被用上：写在一份和项目绑定的文档里，下次开工没人打开；一次写二十条，混着通用常识，十个项目后没人读得完；规则变了，旧经验还在被执行。

「复盘书」是一个 Agent Skill。它不教 AI 怎么分析（AI 本来就会），只管三件事：**存什么、怎么存、下次怎么被想起来**。

## 三个动作

| 动作 | 什么时候 | 做什么 |
|---|---|---|
| **复盘入库** | 项目结束、出了事 | 读材料、追问，提炼 2–4 条过了六项检验的教训；查重合并后存进跨项目经验库 |
| **开工唤醒** | 接新项目、写方案、排期 | 从库里翻出相关的坑、基准和情报，**写进计划本身**，并记账 |
| **体检** | 定期，或发现某条不对 | 合并重复、复核过期、按实际效果把教训升级或证伪 |

闭环：唤醒时记下「这次用了哪几条」，复盘时回头看「它们有没有用」。有用的升级为「多次验证」，误导的收窄或证伪。经验库越用越准，而不是越堆越多。

## 合格教训的六项检验

1. **有触发点**：下个项目里，谁、在哪一步、看到什么时会想起它
2. **有动作**：照做的话哪个决定会不同；说不出来就是空话
3. **有证据**：事实和推断分开写
4. **归因经得起追问**：排除混杂，一次项目只算「单次观察」
5. **有边界**：什么情况下不适用
6. **下次 AI 自己想不到**：通用常识不入库；**本团队的数据基准和合作方脾性**最值钱

## 为什么不会被模型迭代取代

模型越强，复盘分析越好，但它永远不知道：你们团队上次在哪个客户、哪个环节、付出了多少代价；你们自己的 CPM 是多少；哪个客户的法务要审两周。这个 skill 存的正是这些东西，并且保证它们在对的时刻出现。评测见 [evals/README.md](evals/README.md)：同一份项目素材，不装 skill 的 AI 写出 20 条清单，装了以后入库 5 条，每条都有触发点、证据和边界；到了新项目，它只靠一行规则就召回了相关教训，并据此算出了排期冲突。

## 安装与使用

一条命令安装（需要 Node.js 22.20+，会自动检测你电脑上的 Claude Code、Codex、Cursor、Gemini CLI、Trae、Qoder 等 Agent，让你选装到哪些）：

```bash
npx skills add isa-moon/retro-playbook -g
```

也可以手动把整个仓库文件夹放进 Agent 的 skills 目录（如 Claude Code 的 `~/.claude/skills/retro-playbook/`）。

装好后在对话里说：

- 「复盘书，帮我复盘一下这个项目，材料在 xxx」
- 「新项目开工，查一下经验库」
- 「经验库体检」

第一次使用时会问你经验库放在哪（默认 `~/Documents/经验库`，团队可放共享盘或 Git），并征求你同意后在全局规则里加一行，让以后开工自动查库。

## 对环境的要求

- 需要能读写本地文件的 Agent（Claude Code、Codex、Cursor 等）。网页版对话的文件不会跨对话保存，经验库留不住。
- 经验库是纯 Markdown 文件夹，人和 AI 都能直接读写，可以放进共享盘、Git、Obsidian。
- `scripts/lessons.py` 只用 Python 标准库，没有第三方依赖。没有 Python 时，按文档手工也能走完全流程。
- 永不删除教训：归档是移动；所有写入先预览、经你确认。
- 适用任何项目。营销项目另外附了高信号区清单（`references/marketing.md`）。

## 文件

```
retro-playbook/
├── SKILL.md                  主文件：判断动作、六项检验、铁律、完成标准、闭上环
├── references/
│   ├── capture.md            复盘入库流程（回填 → 读材料 → 找信号 → 追问 → 归因陷阱 → 查重 → 写入）
│   ├── recall.md             开工唤醒流程
│   ├── lint.md               体检流程
│   ├── lesson-format.md      教训文件格式、四种类型、复核期
│   └── marketing.md          营销项目高信号区与示例
├── scripts/lessons.py        建库 / 检索 / 体检 / 记账 / 归档 / 回填追踪
└── evals/                    评测素材、基线、装 skill 后的产出、评分表
```
