# 营销项目：高信号区与示例

营销项目的教训通常集中在下面这些地方。复盘时按这张表扫一遍材料，开工唤醒时也按它提取风险信号。表里只列「去哪里看」，不预设答案：每个项目的真相要从它自己的材料里找。

## 高信号区

| 环节 | 去看什么 | 常见的「基准 / 情报」原料 |
|---|---|---|
| brief 与 KPI | KPI 是否可控、口径是否写清（含不含投流、加权还是简单平均、数据由谁提供）；每个 KPI 有没有对应的执行动作 | 客户真正在意哪个 KPI；客户侧数据多久能拿到 |
| 卖点与合规 | 卖点是否涉及需要资质或报告支撑的宣称（功效、医疗、绝对化用语、比较广告）；改卖点发生在哪个时点、谁提出的 | 某客户的审核链路和真实周期；哪些词在某品类一定会被打回 |
| 资源锁定 | 达人、主播、媒体、场地、供应商：口头确认到书面锁定之间隔了多久；改档和违约是谁先提的 | 某机构、某平台资源在旺季的履约情况 |
| 审核与返工 | 每轮审核用了多久；返工次数；返工发生在拍摄前还是拍摄后（后者代价高一个量级） | 某客户各审核方的平均回复时长 |
| 投放与优化 | 预算挪用的时点和依据；临场加热或砍量的决策；自然流和付费流有没有分开记 | 本团队在某品类、某量级、某平台上的 CPM / CPE / ROI 实际区间 |
| 数据真实性 | 互动结构异常（评论/播放、评论/点赞明显偏离同组）、评论内容同质化；发现后怎么处理的 | 哪些机构、哪类账号出过问题 |
| 节奏 | 内容上线是否挤在窗口末尾；有滞后效应的 KPI（搜索、进店、复购）留没留观察期 | 某类 KPI 从内容上线到见效通常隔几天 |
| 结案与结算 | 结案口径和 kickoff 约定是否一致；有没有被搁置、待对客户说明的问题 | 某客户对结案报告的关注点 |

## 归因提醒

营销数据的对比几乎都带着混杂：

- 资源 A 比 B 好 → A、B 是否同时上线、同一版卖点、同样的投流加热？
- 某个时段、某类内容效果好 → 是不是恰好配了主推货品、更大的优惠或平台流量扶持？
- KPI 没达成 → 是策略问题，还是节奏问题（上线太晚、观察期不够），还是口径问题？

一个项目的对比只能算「单次观察」。基准类教训必须写明样本量和条件。

## 示例

下面三条来自一个虚构的 618 零食直播项目，只用来校准写法，不是预置的经验。

```markdown
---
id: L0003
title: 多重优惠叠加必须实际下单验证到手价
when: 直播间同时挂店铺券、平台券或满减中的两种以上时
do: 开播前 2 小时用测试账号对每个链接下单到支付页，截图到手价，对照底价表，运营与客户双方确认后才开播
scope: 只挂单一优惠、平台当天无叠加活动时，可改为抽查主推链接
type: 避坑
tags: 直播电商, 价格, 上播前检查
confidence: 单次观察
cost: 券叠加后到手价低于成本 12 元，前 20 分钟卖出 1300 单，亏损约 1.6 万
source: 复盘/2026-06-20-某零食品牌618直播.md
created: 2026-06-20
review_by: 2026-12-20
---
```

```markdown
---
id: L0004
title: 零食类腰部主播坑位费 ROI 参照区间
when: 给零食、休闲食品类客户做直播排期，评估腰部主播报价时
do: 用 ROI 1.2–1.8 作为腰部坑位费的预期区间做测算；报价按此测算 ROI < 1 的，先要佣金比例或保量条款
scope: 样本仅 3 场，均为大促期；日常期和其它品类不适用
type: 基准
tags: 直播电商, 零食, 报价, 基准
confidence: 单次观察
cost: 三场坑位费合计 18 万，GMV 合计 26.4 万
source: 复盘/2026-06-20-某零食品牌618直播.md
created: 2026-06-20
review_by: 2026-12-20
---
```

空话改写对照：

| 复盘会原话 | 问题 | 改写方向 |
|---|---|---|
| 跟客户沟通要加强 | 没有时点、没有动作 | 是哪一次沟通断了？→ 写成那个节点上的具体动作 |
| 下次要提前准备 | 提前多少？准备什么？ | 找到滑期的源头节点 → 写成倒推的检查点 |
| 某类资源效果好，以后多用 | 可能有混杂 | 先排除干扰因素；成立的话写成基准，带样本量 |
| 数据可能有水分，下次注意 | 没有判别方法 | 写清这次是怎么发现的（哪个指标偏离多少）→ 变成选号时的检查动作 |
